# homebrew-tap

Homebrew formulae for [its-magdy](https://github.com/its-magdy) tools.

## Usage

```sh
brew tap its-magdy/tap
```

## Available formulae

| Formula | Description | Install |
|---------|-------------|---------|
| `tl` | CLI-first translation tool with glossary enforcement and local models | `brew install its-magdy/tap/tl` |

## Quick install

```sh
brew install its-magdy/tap/tl
```
